# Project Conduct

We collaborate respectfully and in good faith. Reviews should challenge code and reasoning with
evidence while treating contributors with patience and dignity.

Expected behavior includes welcoming questions, stating assumptions, accepting correction, giving
actionable feedback, respecting privacy and consent, and taking responsibility for mistakes.
Unacceptable behavior includes harassment, threats, discrimination, sexualized conduct, deliberate
intimidation, disclosure of private information, malicious disruption, or retaliation for a good-faith
report.

This policy applies to repositories, issue trackers, review threads, chats, release spaces, and
public situations where someone represents the project. Report conduct concerns through the private
channel described in [`SECURITY.md`](SECURITY.md), not a public issue.
